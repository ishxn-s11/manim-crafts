# manim-crafts

A collection of visually engaging animations built using Manim (Mathematical Animation Engine) and Python. This repository explores mathematical concepts, algorithms, physics, and computer science through programmatic animations and interactive-style visual explanations.

From elementary mathematics to advanced topics in linear algebra, calculus, artificial intelligence, and physics, this repository serves as a creative playground for exploring how mathematical ideas can be communicated visually.

# Objectives

* Visualize complex mathematical concepts in an intuitive way.

* Develop educational animations using Python.

* Explore algorithm visualization and computational thinking.

* Experiment with mathematical storytelling and motion graphics.

* Build reusable Manim scenes and animation components.
